# Nguyen Hung Manh CV

Personal bilingual CV website for Nguyen Hung Manh, built with Vinext/Next and
styled from the provided SAPP Academy design-system tokens without using the
SAPP logo.

## Features

- Vietnamese is the default language.
- Language combobox switches between Vietnamese and English.
- Responsive layout for mobile, tablet, laptop, and desktop screens.
- Download links for both PDF CV versions.
- LinkedIn and HUST/Rikkeisoft Data Analysis certificate verification links.

## Development

```bash
npm install
npm run dev
npm run build
```

## Important Files

- `app/page.tsx`: bilingual CV content and page structure.
- `app/globals.css`: responsive visual design based on gold/ink tokens.
- `public/manh-profile.png`: profile image extracted from the supplied CV.
- `public/nguyen-hung-manh-cv-vi.pdf`: Vietnamese CV download.
- `public/nguyen-hung-manh-cv-en.pdf`: English CV download.
